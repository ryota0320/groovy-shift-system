# 給与明細テンプレート対応

- 文書状態: レイアウト基準
- 最終更新日: 2026-09-04
- 関連文書: [要件定義](requirements.md)

本書は、提供された給与明細PDFを実装へ反映するための対応表である。元PDFの視覚構造を基準とし、本書だけを根拠に独自デザインへ変更しない。

元PDFには個人名・給与額が含まれるため、現時点ではリポジトリへ複製していない。実装用の固定テンプレート資産が必要な場合は、個人情報を除去した版を作成して管理する。

## 1. 用紙・全体構造

- A4横向き
- 白背景
- 左上に会社名、対象年月、氏名
- 表上部中央に「給与支給明細」
- 左端に縦書き相当のブロック見出し
- ブロックは「勤怠」「支給」「控除」「合計」の順
- 項目行は淡い青、合計ブロックはグレーを基調とする
- 黒い罫線でセルを明確に区切る
- 金額は右寄せし「円」を付ける

## 2. 固定表示

```text
株式会社Groovy
YYYY年MM月
氏名：スタッフ名 様
```

中央見出し:

```text
給与支給明細
```

## 3. 項目対応

| テンプレート項目 | 初期版の扱い                               |
| ---------------- | ------------------------------------------ |
| 就業日数         | 未使用。空欄または非表示                   |
| 出勤日数         | 表示                                       |
| 労働時間         | 表示                                       |
| 欠勤日数         | 未使用                                     |
| 休日出勤日数     | 未使用                                     |
| 有給休暇日数     | 未使用                                     |
| 平日普通残業     | 未使用                                     |
| 平日深夜残業     | 「深夜加算対象時間」へ表示名を変更して使用 |
| 遅刻早退時間     | 未使用                                     |
| 有給残日数       | 未使用                                     |

### 3.2 支給ブロック

| テンプレート項目       | 初期版の扱い                     |
| ---------------------- | -------------------------------- |
| 基本給                 | `base_pay`                       |
| 役職手当等の未使用セル | 「歩合」として`commission`を配置 |
| 資格手当               | 未使用                           |
| 住宅手当               | 未使用                           |
| 家族手当               | 未使用                           |
| 通勤手当               | `transportation_fee_total`       |
| 残業手当               | 未使用                           |
| 深夜勤務手当           | `late_night_pay`                 |
| 法定休日手当           | 未使用                           |

歩合は支給ブロック上段の基本給に続く手当セルへ配置する。元PDFの列幅と4ブロック構造を保ったA4横1ページで、文字切れがないことをPhase 5の視覚検証で確認済みとする。

## 4. 表示形式

- 年月は`YYYY年MM月`とする。
- 時間は「X時間Y分」またはテンプレート内で読みやすい統一形式とする。
- 金額は3桁区切りの整数円とする。
- 0円項目を`0円`とするか空欄にするかは同一PDF内で統一する。
- 店舗別勤務内訳、課税・非課税交通費の内訳は表示しない。
- PDF上の通勤手当には交通費合計を表示する。

## 5. ファイル・品質

- 個別ファイル名は`YYYY年MM月_氏名_給与明細.pdf`とする。
- 日本語フォントを埋め込むか、生成環境で安定して利用可能にする。
- 文字切れ、重なり、黒四角、罫線欠けを許容しない。
- Docker環境で生成し、PDFを画像化して目視確認する。
- スマートフォンブラウザで表示・保存を確認する。
- PDF生成には保存済み月次給与結果を使用し、表示時に再計算しない。
- 氏名には表示名を使用せず、「氏＋半角スペース＋名」の正式氏名を使用する。
- 総支給額が0円の給与結果は個別・一括とも明細出力対象外とする。
