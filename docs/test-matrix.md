# テストマトリクス

- 文書状態: 運用中
- 最終更新日: 2026-09-03
- 関連文書: [要件定義](requirements.md)、[計算ルール](calculation-rules.md)

本書は最低限必要な自動テストと受入確認を定義する。各IDは実装後のテスト名、データセット、Issue等から参照できるようにする。

## 1. テスト種別

| 種別       | 対象                                                               |
| ---------- | ------------------------------------------------------------------ |
| Unit       | 日時変換、深夜、単価解決、端数、税額等の純粋計算                   |
| Feature    | バリデーション、認証、DB保存、トランザクション、ファイルレスポンス |
| Frontend   | 入力操作、警告、未保存、レスポンシブ表示                           |
| Visual     | PDF、XLSX、PNGのレイアウトと文字化け                               |
| Acceptance | スマートフォン・タブレット・PCでの業務フロー                       |

## 13. 実装時の更新ルール

- 実装したテストファイルから本IDをコメントまたはテスト名で参照する。
- 要件追加時は、実装前に対応テストを本書へ追加する。
- 境界値の期待結果を変更する場合、[計算ルール](calculation-rules.md)と[変更履歴](changelog.md)も更新する。
- Visualテストは生成物を画像化して目視確認し、確認環境を記録する。
- フェーズ完了時に対象IDの未実装・失敗がないことを確認する。
