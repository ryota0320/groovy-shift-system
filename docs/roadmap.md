1. フェーズ開始時に対象要件とデータ構造を再確認する。
2. 実装と同時にUnit/Featureテストを追加する。
3. 要件変更が発生した場合、先に正本文書と変更履歴を更新する。
4. Docker上で自動テストとブラウザ確認を行う。
5. 完了条件を満たしてから次フェーズへ進む。
6. 後続フェーズのための仮実装を残す場合は、未完了として明示する。
