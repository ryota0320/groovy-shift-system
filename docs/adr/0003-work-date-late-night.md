# ADR-0003: 深夜加算区間をwork_dateから構築する

- 状態: Accepted
- 決定日: 2026-09-03

## 背景

本システムでは、日跨ぎ勤務を前日の営業日へ帰属させる。深夜加算は会社独自ルールとして営業日22:00から翌8:00までであり、実日時の時刻部分だけでは正しい営業日帰属を判定できない。

## 決定

勤怠レコードの`work_date`を基準に次の区間を作り、勤務区間との重複分数を計算する。

```text
late_night_start = work_date 22:00
late_night_end   = work_date + 1日 08:00
```

翌朝部分も全て元の`work_date`へ帰属させる。実時刻が01:00〜05:00であることだけを理由に深夜判定しない。

例:

```text
work_date:   2026-09-04
clock_in_at: 2026-09-05 01:00
clock_out_at: 2026-09-05 05:00
late_night_minutes: 240
```

## 影響

- `work_date`を`clock_in_at`の日付から単純導出しない。
- 日時選択UIは選択営業日から「当日」「翌日」を明確に組み立てる。
- 深夜計算Serviceは`work_date`を必須入力とする。
- 境界テストを営業日と実日時の両方を明示して作成する。
