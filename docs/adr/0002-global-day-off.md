# ADR-0002: 休みを店舗非依存のシフト行として保存する

- 状態: Accepted
- 決定日: 2026-09-03

## 背景

「休」は店舗ごとの状態ではなく、スタッフ本人の営業日単位の休日である。複数店舗所属者について、店舗ごとに休みを重複保存すると不整合が起きる。

1スタッフ×1営業日は次のどちらか一方でなければならない。

1. 1店舗の勤務予定
2. 全店舗共通の休み

## 決定

`shifts`をスタッフ×営業日で一意にし、`off`行は店舗を持たない。

```text
time/early/help: store_id = 勤務店舗
off:        store_id = NULL
```

UNIQUE(`staff_id`, `shift_date`)を設定する。

## 理由

- 複数店舗勤務をDB制約で防止できる。
- 勤務と休みの競合をDB制約で防止できる。
- 複数店舗への休み重複保存が不要になる。
- 店舗を変更しても休日という意味が変わらない。

## 影響

- 店舗別シフト画面では、対象スタッフの`store_id = NULL`の休みも読み込んで表示する。
- `off`登録時に店舗所属を要求しないが、対象日の在籍は検証する。
- `time`/`early`/`help`では店舗、在籍、所属、店休日を検証する。
- DBのCHECK制約とLaravel側検証を併用する。
