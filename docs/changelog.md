# 仕様変更履歴

本書には、計算結果、データ構造、運用へ影響する重要な仕様変更を記録する。細かな文言修正はGit履歴だけで管理してよい。

## 2026-09-04

### スタッフ氏名・表示名と給与明細出力対象

- スタッフ氏名を氏・名へ分割し、フルネームは間に半角スペースを入れるようにした。任意の表示名を追加し、シフト・勤怠では表示名を優先、未設定時は正式氏名を使用する。
- スタッフ登録・編集・一覧検索・初期移行テンプレートを氏、名、表示名へ対応させ、既存氏名は移行時に分割して保持する。
- 給与一覧、給与明細PDF、集計帳票は表示名にかかわらず正式氏名を使用する。
- 給与明細は計算済みかつ総支給額1円以上の場合だけ個別取得でき、一括ZIPも同条件のスタッフだけを収録するようにした。

### 勤怠の営業日境界

- 店舗の営業時間と切り離した全店共通の営業日切替時刻を12:00とし、実出勤を基準に`work_date`を確定するようにした。
- 当日01:00〜05:00を同日の`work_date`で送信するような不正入力をRequest、時間計算Service、MySQL CHECK制約の3層で拒否するようにした。
- 実出勤・実退勤を15分単位の手入力欄に変更し、退勤の翌10:00固定上限を廃止した。実出勤より後で、24時間未満の勤務であることを検証する。
- 店舗の開店・閉店時間はシフト開始候補にのみ使用し、勤怠の営業日切替と分離した。
- 日別シフト、日次勤怠、ダッシュボードの日付指定なし初期表示を現在営業日へ統一した。午前0:00〜11:59は前日、12:00以降は当日を表示し、明示した日付はそのまま優先する。

### 給与明細ZIPの同姓同名対応

- 同姓同名でZIP内の給与明細名が重複する場合、2件目以降のみファイル名へスタッフIDを付与し、上書きによる欠落を防ぐようにした。

### 月間シフトの選択・スタッフ追加方法

- 月間シフトのセル内に分かれていた開始時刻と勤務店舗のプルダウンを1つへ統合した。自店勤務は「19」「早」、他店ヘルプは開始時刻を持たない「オニカイ」「蛸福」のような店舗名だけの選択肢とする。
- 翌日00:00は保存値を`00:00`のまま維持し、シフト画面では「24」または「24:00」と表示する。
- 月間シフトは表示店舗へ所属するスタッフを基本表示し、対象月の横にある「スタッフ追加」から他店所属スタッフを表の最下部へ追加できるようにした。
- 追加スタッフは店舗×対象月で保存し、再読み込み後も維持する一方、翌月へは自動で引き継がない。
- 対象月に表示店舗へ所属していないスタッフ行を一覧から削除できるようにした。月間シフトの追加登録がなく、既存シフトによって表示された所属外スタッフも対象とする。
- 削除時は対象月に表示店舗で勤務するシフトだけを削除し、所属店舗・別店舗のシフト、全店舗共通の休み・急な休み、スタッフ情報、所属情報、勤怠実績は保持する。表示店舗の所属スタッフは削除できない。
- 月間シフトの選択欄を80px幅へ縮小し、選択文字を中央揃えにした。
- 月間シフトのスタッフ行へライト・ダーク両テーマ対応の控えめな交互色を追加した。土曜・日曜・店休日セルは列側の配色を優先する。

### Phase 5 集計・ファイル出力

- 店舗別月次集計、営業日別人件費、全店舗横断スタッフ集計を追加した。社員の勤務時間は集計し、社員給与は対象外として表示する。
- 日別・店舗別人件費は勤怠日当日の履歴単価を使用し、丸め前金額を集計単位まで保持して最後に切り上げる。歩合は含めず、正式給与額は保存済みのスタッフ月次給与を使用する。
- 画面と同じ集計結果から「店舗別月次集計」「全店舗横断集計」の2シートを持つXLSXを生成できるようにした。
- 添付給与明細を基準に、A4横・勤怠／支給／控除／合計の4ブロックからなる給与明細PDFを実装した。給与一覧から個別PDF、支給対象者分のZIPを取得できる。
- 未計算、総支給額0円、または再計算が必要な給与はPDF出力を拒否し、一括ZIPは総支給額1円以上の対象者を事前検証して一部成功を発生させない。
- 月間シフトを、店舗、年月、全日付、全スタッフ、シフト内容を含む操作部品なしのPNGとして出力できるようにした。
- DockerイメージへDompdf、GD/Freetype、IPAゴシック、Popplerを追加し、日本語フォント、長い表、UTF-8ファイル名、未認証アクセス拒否を自動テストと画像化で確認した。

## 2026-09-03

### 店休日の年月別管理

- 店舗編集画面の店休日を対象年月ごとに取得・表示し、登録件数に応じて全期間分が下へ伸び続けないようにした。
- 月入力と前月・翌月ボタンを追加し、選択月の登録件数と日付昇順の一覧を確認できるようにした。
- 店休日の追加日付を対象月内へ限定し、対象年月と異なる日付の直接送信も拒否するようにした。

### 店舗別の営業時間とシフト開始候補

- 店舗ごとに開店時間と閉店時間を登録・編集できるようにし、新規登録時の初期値を17:00〜10:00とした。
- シフト開始時刻は実際の勤務店舗の営業時間内に限定し、日を跨ぐ場合は23:00から0:00へ続けて閉店時間まで表示するようにした。
- 開店時間が正時でなければ次の正時、閉店時間が正時でなければ直前の正時を候補境界とし、ヘルプ先変更後に営業時間外となる時刻は最初の有効時刻へ調整する。
- 営業時間外の直接送信もサーバー側で拒否し、早番・休み・急な休み等の時刻以外の選択肢は維持した。

### 店休日所属スタッフの他店ヘルプ

- 所属店舗が店休日でも、営業中の他店舗へのヘルプ勤務を登録できるようにした。
- 月間シフトの店休日セルはプルダウンを表示せず、「店休」の固定表示へ戻した。他店勤務は勤務先店舗の月間表でスタッフを追加して入力する。
- 店休日の背景色は、強調表示前の控えめなアンバー系配色へ戻した。
- ヘルプ勤務は実際の勤務店舗へ帰属し、同店舗の勤務人数・日次勤怠・給与集計へ反映する。全店舗が店休日の場合は従来どおり編集不可とする。
- 他店ヘルプ勤務予定があるスタッフは所属店の日次勤怠で勤務先を明示して入力不可とし、ヘルプ先店舗だけで勤怠登録できるよう保存時にも検証する。

### 月次追加スタッフの連続入力

- 追加スタッフへ1日分のシフトを保存すると追加状態が失われ、残りの日が入力不可になる不具合を修正した。
- 追加状態を店舗×対象月で維持し、別店舗に既存シフトがある日だけを競合表示・入力不可とした。
- 追加スタッフをドラッグ移動してからシフトを保存すると最下部へ戻る不具合を修正し、店舗別の保存済み表示順を維持するようにした。
- 所属店でヘルプ先を選択した予定へ、ヘルプ先店舗のシフト画面から開始時刻を登録できるようにした。時刻登録後は所属店にヘルプ先店舗名、ヘルプ先に開始時刻を表示する。
- 追加スタッフが同日に別店舗で勤務しているセルは、「他店」ラベルではなく「－」を選択した無効なプルダウンとして表示する。

### 日別シフトの選択欄統合

- 日別シフトも月間シフトと同じ1つのプルダウンへ統一し、勤務店舗専用のプルダウンを削除した。
- 自店勤務は開始時刻、他店ヘルプは開始時刻を持たない店舗名だけの選択肢として表示する。
- 交代・応援スタッフ追加欄の最大幅を抑え、スタッフ選択と追加ボタンを同じ行・同じ高さに揃えた。スマートフォンでは縦並びにする。
- 店舗・対象日の絞り込み欄と交代・応援スタッフ追加欄は、PCでは横並び、スマートフォンでは縦並びにする。入力欄と前日・翌日ボタンは同じ高さに揃え、店舗・対象日へ残り幅を均等配分しながら各操作の間隔を統一する。

### ダッシュボード・シフト・勤怠の表示整合性

- ダッシュボードの「本日のシフト」を「本日の勤務予定」へ明確化し、表示店舗で勤務する人数と、所属スタッフの自店勤務・休み・他店勤務・シフト未設定の内訳を分けて表示するようにした。
- 日次勤怠に対象日の所属スタッフ全員を表示し、シフト未設定者も一覧から直接実績入力できるようにした。勤務実績保存後は急な出勤として扱う。
- 月間シフトで保存した店舗別スタッフ順を日別シフト・日次勤怠にも反映し、未保存時の基本順を社員ID昇順、アルバイトID昇順へ統一した。スタッフ一覧・給与一覧も同じ基本順を使用する。
- 休み・急休は勤務予定人数や勤怠入力対象へ混入させず、他店所属者の急な出勤と代替候補は従来どおり追加できるようにした。

### 店休日の表示順

- 店舗編集画面の店休日一覧を日付の昇順（古い日付から新しい日付）で表示するようにした。

### 月間シフトのスタッフ表示順

- 月間シフトの初期順をスタッフ一覧と同じ社員ID昇順、アルバイトID昇順へ統一した。
- スタッフ名のドラッグ＆ドロップで行を入れ替え、並び順を店舗ごとに保存するようにした。対象月を変更しても保存順を維持し、未保存の新規スタッフは基本順で補完する。

### スタッフ初期移行の入力補助

- スタッフキーを任意入力とし、空欄または列なしの場合は行ごとに別スタッフとして自動採番するようにした。同一スタッフを複数行へ記載する場合は、従来どおり明示した同一キーでまとめる。
- 所得税設定行の扶養人数が空欄の場合は0人として登録するようにした。
- 日付は`YYYY-MM-DD`、`YYYY/MM/DD`、Excel日付セルを受け付け、Excel上の表示形式に依存せず読み取るようにした。
- スタッフ一覧は社員をID昇順で先に表示し、続けてアルバイトをID昇順で表示するようにした。
- スタッフ一覧の対象日検索を廃止し、在籍・所属・時給は常に本日時点を表示するようにした。
- スタッフ一覧を25件単位でページングし、表示範囲、総件数、現在ページを確認できるようにした。

### シフトのヘルプ勤務店舗

- シフト作成時に、表示中の自店だけでなく他の有効店舗をヘルプ先として選択できるようにした。ヘルプ先への所属登録は不要とする。

- ヘルプ勤務シフトがある場合は、ヘルプ先への所属登録がなくても同店舗で勤怠を登録できるようにした。
- シフトのない急な出勤も、対象日にいずれかの有効店舗へ所属していれば、自店・他店を問わず登録できるようにした。

### 給与端数

- 正式給与をスタッフ×月の結果とした。
- 日別整数を合算せず、丸め前精度を保持して各表示単位の最後に切り上げることにした。
- 日別・店舗別表示と正式給与の端数差を許容することにした。

### 在籍・店舗所属

- `employment_status`を廃止した。
- `hired_at`と`retired_at`から在籍状態を導出することにした。
- 店舗所属を適用期間付き履歴へ変更した。

### 全店舗共通の休

- 「休」を店舗状態ではなくスタッフ×営業日の全店舗共通状態とした。
- 1スタッフ×1営業日を、1店舗勤務または休みのどちらか一方に限定した。
- 論理モデルでは`shifts.store_id = NULL`の`off`として一意に保存する方針にした。

### 店休日の勤務

- 店休日の通常シフト禁止を維持した。
- 確認ダイアログ後の勤怠登録を可能にした。
- 店休日勤務も勤怠・交通費・人件費・給与へ含めることにした。

### 深夜加算

- 深夜区間を`work_date 22:00`から翌日8:00までに確定した。
- 翌朝部分も全て元の`work_date`へ帰属させることにした。
- 実時刻だけによる深夜判定を禁止した。
- 実日時が2026-09-05 01:00〜05:00の勤務は、2026-09-04営業日の勤務として扱うことを明記した。

### 勤怠削除と再計算

- 確認後の勤怠削除を可能にした。
- 給与計算入力の変更後、対象給与を「再計算が必要」とすることにした。

### 給与明細

- 提供された給与明細PDFをレイアウト基準に確定した。
- 独自デザインを作成しないことを明記した。
