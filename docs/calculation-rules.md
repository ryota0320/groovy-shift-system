# 計算ルール

- 文書状態: 確定仕様
- 最終更新日: 2026-09-04
- 関連文書: [要件定義](requirements.md)

本書は、勤怠・深夜・人件費・給与・所得税の計算結果を一意にするための正本である。画面、PDF、XLSXごとに計算を再実装せず、共通Serviceの結果を使用する。

## 1. 共通原則

- アプリケーションのタイムゾーンは`Asia/Tokyo`とする。
- 日付・日時はDBで通常の日付型・日時型として保存する。
- 「26:15」のような拡張時刻をDBへ保存しない。
- 時間量は整数分で扱う。
- 確定金額は整数円で保存する。
- 比例計算の途中値は有理数またはDecimal相当の精度で保持する。
- 給与確定値にbinary floating pointを使用しない。
- 1円未満の端数は、定められた集計単位の最終段階で切り上げる。

## 2. 営業日と日時

### 2.1 work_date

`work_date`は勤務実績が属する営業日であり、`clock_in_at`のカレンダー日付と常に一致するとは限らない。

```text
work_date:   2026-09-04
clock_in_at: 2026-09-05 01:00
clock_out_at: 2026-09-05 05:00
```

上記勤務は2026-09-04営業日の勤務として扱う。`clock_in_at`の日付だけを見て`work_date = 2026-09-05`へ変更しない。

日付指定なしで日次関連画面を開く場合の現在営業日`D`は、Asia/Tokyoの現在日時を基準に次のように決める。

```text
現在時刻 < 12:00 なら D = 前日のカレンダー日付
現在時刻 >= 12:00 なら D = 当日のカレンダー日付
```

この初期値は日別シフト、日次勤怠、ダッシュボードへ共通適用する。URLや画面操作で日付が明示された場合は、指定日を優先する。

### 2.2 入力日時の組み立て

- 日次勤怠画面で選択されている`work_date`を基準に実日時を組み立てる。
- 営業日切替時刻は全店共通で12:00とする。
- 実出勤の手入力時刻が12:00以降なら`work_date`当日、0:00〜11:59なら`work_date + 1日`の実日時として組み立てる。
- 実退勤は実出勤より後に現れる最初の手入力時刻として組み立てる。これにより15:00〜翌13:00のような勤務も日付を伴う実日時へ一意に変換できる。
- シフト開始時刻は勤務店舗の開店時間を起点とし、1時間単位で閉店時間まで表示する。日を跨ぐ場合は23:00に続けて0:00から並べ、開店時間は次の正時、閉店時間は直前の正時を境界とする。
- `work_date`のシフト予定が00:00〜10:00の場合は、表示上は「1:00」等として、内部では翌日側のオフセットで比較する。例えば9月4日の`01:00`シフトは、実日時9月5日01:00と一致する。
- 出勤・退勤とも15分境界でなければならない。
- `clock_out_at > clock_in_at`を必須とする。
- `clock_out_at - clock_in_at < 24時間`を必須とする。
- 店舗の開店・閉店時間はシフト候補にのみ使用し、勤怠の営業日切替に使用しない。

## 3. 実働時間

休憩、中抜け、1日複数勤務を扱わないため、実働は単純差分とする。

```text
working_minutes = clock_out_at - clock_in_at
```

例:

```text
21:00〜翌02:15 = 315分 = 5時間15分
```

## 4. 深夜加算対象時間

### 4.1 深夜区間

営業日`D`の深夜加算対象区間は半開区間として次のように定義する。

```text
late_night_start = D 22:00
late_night_end   = D + 1日 08:00
late_night_range = [late_night_start, late_night_end)
```

勤務区間も`[clock_in_at, clock_out_at)`として扱う。

```text
late_night_minutes
= minutes(intersection(work_range, late_night_range))
```

境界時刻そのものに長さはないため、22:00退勤は0分、22:00出勤から22:15退勤は15分となる。

### 4.2 営業日への帰属

- 翌0:00〜8:00部分も全て元の`work_date`へ帰属する。
- 翌日営業日の深夜時間へ振り替えない。
- 実時刻が01:00〜05:00という理由だけで深夜判定しない。
- 必ず対象レコードの`work_date`から作成した深夜区間との重複を求める。

### 4.3 境界例

| work_date  | 勤務区間         | 深夜分数 |
| ---------- | ---------------- | -------: |
| 2026-09-05 | 21:45〜22:00     |        0 |
| 2026-09-05 | 22:00〜22:15     |       15 |
| 2026-09-05 | 19:00〜23:00     |       60 |
| 2026-09-05 | 23:00〜翌02:00   |      180 |
| 2026-09-05 | 22:00〜翌08:00   |      600 |
| 2026-09-05 | 21:00〜翌09:00   |      600 |
| 2026-09-05 | 22:00〜翌10:00   |      600 |
| 2026-09-04 | 翌01:00〜翌05:00 |      240 |

最後の例の実日時は2026-09-05 01:00〜05:00だが、`work_date = 2026-09-04`であるため、2026-09-04 22:00〜2026-09-05 08:00と重複する240分を計上する。

## 5. 適用期間付き設定

### 5.1 期間境界

- `effective_from`は適用開始日を含む。
- `effective_to`は適用終了日を含む。
- `effective_to = NULL`は終了日なしとする。
- 同じ計算対象について適用期間を重複させない。

有効条件:

```text
effective_from <= target_date
AND (effective_to IS NULL OR effective_to >= target_date)
```

### 5.2 基準日

| 設定                   | 基準日                   |
| ---------------------- | ------------------------ |
| 時給                   | 勤怠の`work_date`        |
| 店舗別交通費・課税区分 | 勤怠の`work_date`        |
| 深夜加算額             | 勤怠の`work_date`        |
| 甲欄/乙欄・扶養人数    | 給与の`payment_date`     |
| 所得税額表年度         | 給与の`payment_date`の年 |

時給と所得税設定は必須とし、必要な日に有効な設定がない場合や複数ある場合は明示的エラーとする。交通費と深夜加算額は未設定なら0円として扱い、有効な設定が複数ある場合だけ明示的エラーとする。歩合は未登録なら0円とする。必要年度の所得税額表がない場合も明示的エラーとする。

## 6. 給与対象期間と支給日

対象年月を`Y-M`とすると、対象期間と支給日は次のとおりとする。

```text
period_start = Y-M-01
period_end = Y-Mの末日
payment_date = 対象月の翌月10日
```

例:

| 対象月  | 対象期間               | 支給日     | 税額表年度 |
| ------- | ---------------------- | ---------- | ---------: |
| 2026-09 | 2026-09-01〜2026-09-30 | 2026-10-10 |       2026 |
| 2026-12 | 2026-12-01〜2026-12-31 | 2027-01-10 |       2027 |

初期版では土日祝による支給日調整を行わない。

## 7. 基本給

### 7.1 丸め前基本給

スタッフ月内の各勤務日`d`について、その日に有効な時給を`wage(d)`とする。

```text
raw_base_pay
= Σ(working_minutes(d) × wage(d) / 60)
```

月途中で時給が変わる場合も、日別計算値を整数円へ丸めずに合算する。

### 7.2 確定基本給

```text
base_pay = ceil(raw_base_pay)
```

例:

```text
375分 × 1,260円 / 60 = 7,875円
base_pay = 7,875円
```

## 8. 深夜勤務手当

各勤務日`d`に有効な1時間当たり深夜加算額を`late_rate(d)`とする。
有効な設定がない日は`late_rate(d) = 0`とする。

```text
raw_late_night_pay
= Σ(late_night_minutes(d) × late_rate(d) / 60)

late_night_pay
= ceil(raw_late_night_pay)
```

例:

```text
255分 × 150円 / 60 = 637.5円
late_night_pay = 638円
```

## 9. 交通費

### 9.1 発生条件

- 勤怠実績が存在する勤務日だけ発生する。
- シフトだけでは発生しない。
- スタッフ、店舗、`work_date`に有効な設定を使用する。
- 有効な設定がない場合は交通費なしの0円とする。
- 1日複数勤務がないため、1勤怠につき日額1件を加算する。

### 9.2 月次集計

```text
transportation_fee_taxable
= Σ(tax_type = taxable の amount_per_day)

transportation_fee_non_taxable
= Σ(tax_type = non_taxable の amount_per_day)

transportation_fee_total
= transportation_fee_taxable
+ transportation_fee_non_taxable
```

交通費は整数円の日額であるため比例計算の端数は生じない。

## 10. 歩合

- スタッフ×対象年月の`commission`を使用する。
- 未登録時の扱いは0円とする。
- 0以上の整数円とする。
- 全社月次給与と課税対象へ含める。
- 日別・店舗別人件費には含めない。

## 11. 総支給額・課税対象額

```text
gross_pay
= base_pay
+ late_night_pay
+ transportation_fee_total
+ commission
```

```text
taxable_pay
= base_pay
+ late_night_pay
+ commission
+ transportation_fee_taxable
```

非課税交通費は`gross_pay`には含むが、`taxable_pay`には含めない。

## 12. 税額表参照額と所得税

```text
tax_table_reference_amount
= taxable_pay
- social_insurance_deduction
```

初期版で社会保険料等を計算しないスタッフは次のとおりとする。

```text
social_insurance_deduction = 0
```

所得税は次の入力で決定する。

1. `payment_date`の年
2. `payment_date`に有効な`tax_category`
3. 甲欄の場合は`dependent_count`
4. `tax_table_reference_amount`
5. 国税庁の当該年分月額表の金額区分または公式算式

乙欄は公式表の乙欄を使用し、扶養人数による列選択は行わない。必要年度の税額表が存在しない場合は給与計算を失敗させ、誤った0円を返さない。

## 13. 控除・差引支給額

```text
total_deductions
= income_tax
+ other_deductions

net_pay
= gross_pay
- total_deductions
```

初期版で追加控除を入力・計算しない場合、`other_deductions = 0`とする。

## 14. 給与計算手順

1. 対象月の開始日・終了日と翌月10日の支給日を決定する。
2. 対象スタッフがアルバイトであることを検証する。
3. 対象月の全店舗勤怠を取得する。
4. 勤務日ごとの時給、深夜加算額、交通費を解決する。深夜加算額・交通費の未設定は0円とする。
5. `working_minutes`と`late_night_minutes`を合算する。
6. 丸め前基本給と丸め前深夜手当を合算する。
7. 月次単位で基本給と深夜手当を切り上げる。
8. 課税・非課税交通費を合算する。
9. 月次歩合を取得する。
10. 総支給額と課税対象額を算出する。
11. 支給日に有効な税設定と支給年の税額表を取得する。
12. 税額表参照額と所得税を算出する。
13. 総控除額と差引支給額を算出する。
14. トランザクション内で給与結果を保存・更新する。
15. 再計算必要状態を解除する。

## 15. 日別・店舗別人件費

### 15.1 日別

```text
raw_daily_base_pay = working_minutes × wage / 60
raw_daily_late_night_pay = late_night_minutes × late_rate / 60

display_daily_base_pay = ceil(raw_daily_base_pay)
display_daily_late_night_pay = ceil(raw_daily_late_night_pay)
display_daily_total
= ceil(raw_daily_base_pay + raw_daily_late_night_pay + transportation_fee)
```

表示項目ごとに切り上げる場合と合計だけを切り上げる場合で1円差が出得るため、画面とXLSXは同一の集計DTOを使用する。正式給与への再利用はしない。

### 15.2 店舗別月次

店舗内の丸め前基本給相当と丸め前深夜手当をそれぞれ合算し、店舗×スタッフ×月の表示時に切り上げる。日別表示済み整数を合算しない。

### 15.3 正式給与との関係

- 日別・店舗別表示額は管理用の人件費相当額である。
- 表示単位ごとの切り上げにより、店舗別合計と全社月次給与に差が生じ得る。
- 給与明細、所得税、支給額にはスタッフ×月の正式給与結果だけを使用する。

## 16. 給与再計算の無効化条件

計算済み給与に影響する次の変更が発生した場合、対象スタッフ・対象月を「再計算が必要」にする。

- 勤怠の追加、編集、削除
- 勤務日に適用される時給の追加、編集、期間変更
- 勤務日に適用される交通費・課税区分の追加、編集、期間変更
- 勤務日に適用される深夜加算額の追加、編集、期間変更
- 支給日に適用される税区分・扶養人数の追加、編集、期間変更
- 歩合の追加、編集、削除
- 使用中の所得税マスタの訂正

影響月の判定に曖昧さがある場合は、安全側として該当し得る計算済み給与を再計算対象にする。
