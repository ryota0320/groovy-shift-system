# スタッフ初期移行

- 文書状態: 確定
- 対象フェーズ: Phase 1
- 最終更新日: 2026-09-04

## 1. 目的

既存Excelから、スタッフと給与計算に必要な期間付きマスタを初期登録する。過去勤怠・給与結果の移行は対象外とする。

## 2. 対応形式

- CSV（UTF-8、CP932／Shift_JIS）
- Excel Open XML（`.xlsx`）
- 最大5MB、データ2,000行
- 先頭シートの1行目をヘッダーとして読み込む
- CSVの区切り文字はカンマとする

画面からExcelテンプレートを取得できる。テンプレートには入力例と入力方法シートを含める。

## 3. 登録対象

- スタッフの氏、名、任意の表示名、雇用区分、在籍期間
- 店舗所属期間
- アルバイト時給履歴
- 店舗別交通費・課税区分履歴
- アルバイト所得税区分・扶養人数履歴

社員ログインアカウントはインポートしない。移行後、必要な社員だけスタッフ編集画面から作成する。

## 4. 行のまとめ方

- `スタッフキー`は任意入力とし、空欄の場合は行ごとに別スタッフとして自動採番する。列自体がないファイルも受け付ける。
- 明示的に入力した同じスタッフキーの複数行は1名として登録する。
- 複数店舗所属など、同一スタッフを複数行にする場合だけ同じスタッフキーを入力する。
- 氏、名、表示名、雇用区分は、同じスタッフキーの全行で一致させる。
- 店舗名は登録済み店舗と完全一致させる。
- 初期移行では無効店舗も過去履歴の登録先として許可する。
- 同じ内容を複数行に記載した履歴は1件へまとめる。
- 同じ対象の期間重複は拒否する。

## 5. 値の規則

| 項目           | 許可値・形式                                        |
| -------------- | --------------------------------------------------- |
| 雇用区分       | `社員`、`アルバイト`（`employee`、`part_time`も可） |
| 日付           | `YYYY-MM-DD`、`YYYY/MM/DD`、Excel日付セル           |
| 時給・交通費   | 0以上の整数                                         |
| 扶養人数       | 0以上の整数。所得税設定行で空欄の場合は0人          |
| 交通費課税区分 | `課税`、`非課税`（`taxable`、`non_taxable`も可）    |
| 所得税区分     | `甲欄`、`乙欄`（`ko`、`otsu`も可）                  |

氏と名は必須、表示名は任意とする。表示名が空欄の場合、シフト・勤怠等にも「氏＋半角スペース＋名」を表示する。

終了日は開始日以降とし、期間の開始日と終了日は両日とも有効とする。

## 6. エラーとトランザクション

- すべての行を事前検証してから登録する。
- 1件でも不正な行があれば、行番号付きエラーを表示し、ファイル全体を登録しない。
- 空行は登録対象外とするが、エラー行番号は空行を含む元ファイル上の番号を表示する。
- ファイル内の登録処理を1トランザクションで実行する。
- 新規登録専用とし、既存スタッフの更新には使用しない。
- 同じファイルの再送信は重複登録になるため、画面とテンプレートで注意を表示する。

## 7. セキュリティ

- 認証済みの管理画面利用者だけが利用できる。
- CSV／XLSX以外と5MBを超えるファイルを拒否する。
- ファイルを公開領域へ永続保存しない。
